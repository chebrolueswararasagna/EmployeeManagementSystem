# Employee Management System

## Overview

Employee Management System is a Java-based application developed using Object-Oriented Programming (OOP) concepts. The project helps manage employee records efficiently through a simple console-based interface.

## Features

* Add Employee Records
* View Employee Details
* Update Employee Information
* Delete Employee Records
* Search Employee Data

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* BlueJ IDE

## Learning Outcomes

* Implemented CRUD operations
* Applied OOP concepts such as classes and objects
* Improved problem-solving and Java programming skills
